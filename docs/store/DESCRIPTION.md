Dushood

## Package
`com.esteban.dushood` — versionCode 1, versionName 1.0.0

## Description courte
Un monde fabriqué pour toi. Explore, résous, découvre la lettre.

## Description longue
Dushood est un monde construit pour une seule personne.

Guidé par Nayo, une luciole-esprit, tu traverseras le Jardin des Lucioles, la Forêt des Échos,
le Lac des Reflets, la Ville des Lanternes et la Tour des Souvenirs. Chaque lieu garde une énigme,
et chaque énigme garde un fragment d'une lettre écrite pour toi.

- Aventure narrative 2D illustrée, entièrement tactile (tap et glisser)
- 5 énigmes originales avec indices progressifs
- Sauvegarde automatique : reprends où tu t'étais arrêté
- Musique et ambiances génératives
- 100 % hors ligne, sans publicité, sans achat

Prends ton temps. Ce monde t'attend.
